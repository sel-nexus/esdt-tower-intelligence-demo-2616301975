# Changelog

## Workshop modernization

- Replaced the shared demo sign-in prompt with five one-click local personas. Role switches change the starting view without clearing scenario settings, filters, or simulated work. Roles are not permissions; valid legacy demo sessions still open the workshop.
- Refreshed the responsive shell, portfolio KPIs, health/readiness distributions, ranked shortlists, schematic map and results. Portfolio and map use shared search and filters; KPI drill-down retains the active discovery criteria.
- Clarified tower decisions, evidence provenance, validation, illustrative economics, and simulated action priority. Added dedicated Missing Information and Power Upgrades queues while retaining the combined legacy upgrade queue. Export, audit, reset, scoring fixtures and local Samples remain synthetic-only.
- Reset now clears unapplied facilitator inputs even when the committed baseline is unchanged. Missing or unverified cabinet-upgrade proof is treated as a decision gap, not a confirmed blocker; independent confirmed blockers retain precedence.
- Extended Vitest and Playwright regressions and updated the workshop README. No backend, database, configuration migration, or production integration is required.
